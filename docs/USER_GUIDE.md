# User guide
1. Click **Get started** (or **Load demo data**). 2. Upload: tick the schedules you have, upload files (PDF/JPG/PNG/CSV/ICS) or add entries manually. 3. Analysis: see what was extracted per file; warnings mark unreadable rows. 4. Review: fix titles/times, untick "Blocks study" for informational events, resolve conflicts, confirm. 5. Study setup: start date, end date, daily start/end time, hours/day, session and break length, study days, meals/travel. 6. Courses and Deadlines. 7. Study plan -> Generate; read coverage and validation. 8. Planner: week/day/month calendar; click a block to mark Done/Missed; drag a session to move it; drag "Drag a custom event" onto a day. 9. After changes use Regenerate remaining schedule and check the preview. 10. Progress shows completed sessions.
