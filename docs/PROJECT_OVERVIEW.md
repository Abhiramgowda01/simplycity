# Project overview
SmartStudy merges a student's regular timetable, event calendar, CIE and SIE schedules with courses and deadlines, then generates a clash-free study plan inside a start/end date range the student chooses.
**Users:** students of any year/department; class representatives can export/import a shared schedule file (Settings).
**Workflow (sidebar order):** Upload → Analysis → Timetable review → Study setup (start/end dates, daily window, hours/day, sessions, breaks, study days, unavailable time) → Courses → Deadlines → Study plan → Planner calendar → Progress. Any document type may be skipped; manual entry is always available.
**Scope:** browser-only prototype; data in localStorage; no accounts or backend.
