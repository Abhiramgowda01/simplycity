# Conflict detection
Overlap: `a.start < b.end && b.start < a.end` on minutes since midnight. Two fixed events are compared on a date if both are dated and equal, if one is recurring and the other's weekday matches, or if both recur on the same weekday. Holidays cover 00:00-24:00. Identical entries (title, type, day/date, times) are duplicates and dropped by `dedupe`; differing overlapping entries are flagged and shown on Analysis/Review - never overwritten. Only events with "Blocks study" ticked count. Study sessions are checked by `validate`; drag-moving a session is rejected if it introduces a new violation; dropping a personal event displaces overlapped planned sessions.
